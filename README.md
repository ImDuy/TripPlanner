# AI Trip Planner

## Features 🌟

- Login/Signup
- Leverage GeminiAI to generate trip plans based on user's preferences
- Suggest popular places and hotels
## Built With 🛠

- React Native (Expo)
- Typescript
- Context API
- Firebase Authentication, Firebase Firestore
- Google Gemini API
- Google Places API
